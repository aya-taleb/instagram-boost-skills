# Job spec: instagram-story

Written before opening Jake's ig-story. Only his file is the baseline at test time.

**The job.** A founder needs today's (or this week's) stories for one business, planned
frame by frame, so they can shoot and post them in a few minutes a day.

**Who.** A solo founder with one or more businesses. Some are local (a cafe, a truck, a
lunch club) where stories carry the daily news: today's menu, sold out, where we are.

**Inputs.** The active business file, this week's plan.md (story slots), what is happening
today, any offer with a date, and the local block for a place-based business.

**Output.** A numbered frame list: what to shoot or show, the text on screen (short, inside
the safe zone), the sticker (if any) and why, and which frame carries the one ask. A note on
what to save to a Highlight. Saved to stories/<date>.md.

**Good looks like.** 3 to 7 frames. One clear ask per day. At least one frame that invites a
reply (poll, question, quiz, slider), because replies open DMs. Real material, not invented.
Text that fits the 9:16 frame and stays clear of the top and bottom 250 px.

**Must not.** Post, schedule or log in. Invent customers, numbers or events. Use more than one
ask per day. Use a link sticker for a link the user did not give.

**Hands off to.** instagram-dm (for replies that come in), instagram-reply, instagram-plan.
