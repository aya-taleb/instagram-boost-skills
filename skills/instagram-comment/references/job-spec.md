# Job spec: instagram-comment

Written before opening Jake's ig-comment.

**The job.** Draft comments the user leaves on other accounts' posts during the daily
engagement round, so the business gets seen by the right people without pitching.

**Inputs.** The engagement list from plan.md (reach, peers, buyers or partners); the post
text or a description the user pastes for each target (the skill never browses or scrapes
Instagram); the business file for tone and expertise.

**Output.** One comment per post, ready to paste, with a one-line reason it fits; flags for
posts where the user should skip commenting. Optional log of who was engaged and when.

**Good looks like.** Each comment adds something: a specific reaction, a useful detail, a
question the creator would want to answer. It reads as a person. It never pitches, never
links, never says "DM me". Local businesses comment as neighbors.

**Must not.** Post comments, like, follow or browse for the user. Make up experience the
user does not have. Write generic praise ("Great post!").

**Hands off to.** instagram-dm once a real conversation starts; instagram-plan.
